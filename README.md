# Plugins free

Бесплатные плагины для Minecraft-серверов.

| Плагин | Что делает | Последняя версия |
|---|---|---|
| [FoolioBridge](FoolioBridge) | Мост между донат-сайтом и сервером: выдача покупок, офлайн-очередь, подписи HMAC | [1.0.0](FoolioBridge/FoolioBridge-1.0.0) |

Структура: `ИмяПлагина/ИмяПлагина-версия/` — в каждой папке версии лежат готовый `.jar`, исходники и описание.
