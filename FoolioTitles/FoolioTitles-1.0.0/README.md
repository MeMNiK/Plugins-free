# FoolioTitles 1.0.0

Личные титулы для игроков Minecraft-сервера. Игрок покупает на сайте **токен**, создаёт в меню свой титул (с цветами, HEX и градиентами), администрация проверяет его, и после одобрения титул появляется в личном хранилище — его можно надеть, снять или поменять. Титул отображается как **суффикс LuckPerms**.

Бесплатный плагин от Foolio. Работает в паре с [FoolioBridge](../../FoolioBridge) — сайт выдаёт токены командой.

## Требования

- Paper 1.20–1.21+ (или форки: Purpur, Pufferfish), Java 17+
- LuckPerms 5.4+
- Хранение данных — встроенный SQLite (`plugins/FoolioTitles/data.db`), ничего настраивать не нужно

## Установка

1. Положить `FoolioTitles-1.0.0.jar` в `plugins/`.
2. Перезапустить сервер.
3. Настроить `config.yml` и `menus.yml`, затем `/titles reload`.
4. Повесить на товар «Токен титула» на сайте команду выдачи (см. ниже).

## Как это работает

1. Игрок получает токен: `/titles token give <ник> 1` — эту команду выполняет сайт или FoolioBridge.
2. `/titles` → **Создать титул** → **Ввести титул**. Меню закрывается, игрок пишет титул в чат. Сообщение перехватывается, другие игроки его **не видят**.
3. Меню открывается снова с превью: как титул будет выглядеть в чате. Можно ввести заново или **отправить на проверку** (−1 токен).
4. Администрация открывает `/titles admin`: **ЛКМ** — одобрить, **ПКМ** — выбрать причину отказа или написать свою.
5. Если титул отклонён:
   - за первый отказ токен **возвращается**;
   - за второй и следующие — **нет**.

   Число «бесплатных» отказов задаётся параметром `rejections.free-rejections`.
6. Одобренный титул попадает в **«Мои титулы»**. В хранилище только титулы, созданные этим плагином, а не все суффиксы сервера. **ЛКМ** — надеть или снять, **Shift+ПКМ** — удалить.

Игрок получает уведомление о решении, даже если был офлайн: оно придёт при следующем входе.

## Защита

- Двойные клики и автокликеры не приводят к повторным списаниям: меню блокируется на время действия.
- Из меню нельзя вытащить или положить предметы, клавиши Q, цифры и колёсико не нажимают кнопки.
- Удаление своего титула и снятие титула администрацией требуют подтверждения (повторный Shift+ПКМ).
- Между заявками есть кулдаун (`limits.submit-cooldown-seconds`), чтобы нельзя было спамить администрации.
- Титул с плейсхолдерами (`%player_ip%`, `{balance}`) или «склеенными» цветовыми кодами не принимается — чат-плагин не сможет их подставить.
- Админ-действия перепроверяют право `foolio.titles.admin`; выдача токенов ограничена 1 000 000 за раз, баланс не уходит в минус.

Плагин проверен симуляцией на настоящих Paper 1.20.4 и 1.21.1 с LuckPerms: боты-игроки проходят 70 сценариев — создание, проверку, отказы, одобрение, LuckPerms, офлайн-уведомления и попытки эксплойтов.

## Оформление титула

| Ввод | Результат |
|---|---|
| `&cТекст`, `&lТекст` | обычные цвета и стили |
| `&#ff8800Текст` | HEX-цвет |
| `<gradient:#ff4e50:#f9d423>Текст</gradient>` | градиент |
| `<rainbow>Текст</rainbow>` | радуга |
| `<bold>`, `<italic>`, `<underlined>`, `<strikethrough>` | стили |

Клики, ховеры, шрифты и прочие теги MiniMessage запрещены. Длина считается по **видимым** символам, без учёта кодов.

**Автопроверка до отправки** (токен при этом не тратится):
- длина;
- разрешённые символы;
- запрещённые слова, с учётом «обходов» вроде латинских букв вместо русских;
- мигающий текст `&k`.

## Команды

| Команда | Описание | Право |
|---|---|---|
| `/titles` | Меню титулов | `foolio.titles.use` |
| `/titles admin` | Очередь проверки | `foolio.titles.admin` |
| `/titles admin player <ник>` | Титулы игрока, снять за нарушение (Shift+ПКМ) | `foolio.titles.admin` |
| `/titles token give\|take\|set <ник> <кол-во>` | Токены (работает из консоли) | `foolio.titles.admin` |
| `/titles token check <ник>` | Баланс токенов | `foolio.titles.admin` |
| `/titles strikes check\|reset <ник>` | Счётчик отказов игрока | `foolio.titles.admin` |
| `/titles reload` | Перезагрузить конфиги | `foolio.titles.admin` |

Алиасы: `/ftitles`, `/tituly`.

Если игрок ещё ни разу не заходил на сервер, `token give` сохранит токены по нику. Он получит их при первом входе.

### Права

- `foolio.titles.use` — пользоваться титулами (по умолчанию у всех)
- `foolio.titles.admin` — проверка, токены, страйки, перезагрузка (по умолчанию OP)
- `foolio.titles.slots.<N>` — увеличить хранилище до N слотов (например, `foolio.titles.slots.10` для донат-группы)

## LuckPerms

Титул ставится суффиксом с приоритетом `luckperms.priority` (по умолчанию `500`).

**Суффиксы с этим приоритетом считаются принадлежащими плагину**: он сам их заменяет и удаляет. Не используйте этот приоритет вручную.

Формат строки суффикса (`luckperms.suffix-format`):
- `LEGACY` — `&x&f&f&8&8&0&0`, понимают CMI, TAB, EssentialsChat и большинство чат-плагинов (по умолчанию);
- `LEGACY_HASH` — `&#ff8800`;
- `MINIMESSAGE` — теги как есть, если ваш чат-плагин их поддерживает.

Внешний вид суффикса задаётся в `luckperms.suffix-template`, например `" <dark_gray>[</dark_gray><title><dark_gray>]</dark_gray>"`.

## Сборка из исходников

```
cd plugin
gradle build
```

Готовый jar появится в `plugin/build/libs/`. В репозитории jar собирается автоматически через GitHub Actions.
